# 智联电子项目报价单系统（独立版）

从《智联电子开单系统》中提取的「项目报价单」功能，独立运行、独立维护、独立备份。

## 一、如何启动

本项目为纯 HTML + CSS + JavaScript 静态应用，无需安装任何环境：

**方式一（推荐，功能完整）：** 用任意静态服务器启动，例如：

```powershell
# 进入项目目录后任选其一：
npx serve .
# 或
python -m http.server 8080
```

然后浏览器访问 `http://localhost:8080`。

**方式二：** 直接双击 `index.html` 用浏览器打开（编辑、保存、预览、打印均可用；PDF/PNG 导出依赖的 CDN 库需要联网加载）。

## 二、第三方依赖（CDN）

| 库 | 用途 |
|---|---|
| html2canvas 1.4.1 | PNG 导出、PDF 版面渲染 |
| jsPDF 2.5.1 | PDF 文件生成 |

仅在导出 PDF/PNG 时需要联网加载这两个库；其余功能完全离线可用。

## 三、数据存储方案

- 所有报价单数据保存在**浏览器 localStorage**（键名：`project_quotes`）。
- 数据仅存在于当前电脑的当前浏览器中，刷新、关闭重开均不丢失。
- 产品图片压缩为宽约 100px 的 JPEG（质量 0.7）后以 Base64 存入单据，与原系统一致。
- 清除浏览器站点数据会删除报价单，请定期使用「备份/恢复」导出 JSON 备份。

## 四、功能使用说明

- **新建报价单**：点击工具栏「+ 新建报价单」，默认生成两个类目（设备类、安装与服务类）各三行明细，单据编号自动生成（XM+日期+随机号）。
- **编辑**：标题、报价单位、电话可直接点击文字修改；客户信息、项目说明、备注为输入框。
- **类目**：点「+ 新增类目」添加；类目名称可直接改；「删除」按钮删除整个类目（有确认提示）。
- **明细行**：类目右侧「+ 添加产品行」新增；每行末尾「×」删除；数量/单价变化立即重算金额。
- **图片**：点明细行「图片」列的「上传」选择本地图片，自动压缩显示。
- **配色**：工具栏下拉框切换 21 种配色（1 默认渐变 + 10 纯色 + 10 渐变），标题、类目标题、合计行同步变色。
- **含税**：输入税率（默认 13%）后点「含税」按钮计算含税金额。
- **保存**：空白单据会被拦截；编辑历史单据保存时更新原记录、保留原单据编号，不会重复新增。
- **历史单据**：工具栏「☰ 历史单据」进入列表，支持按客户/编号/日期搜索，可打开编辑、预览、删除。
- **预览/打印/导出 PDF/导出 PNG**：均先做有效数据校验，输出版面完全一致（A4 横向）。
- **备份/恢复**：导出全部报价单为 JSON 文件；导入前校验格式并提示覆盖确认。

## 五、如何修改

| 需求 | 修改位置 |
|---|---|
| 默认标题/公司/电话 | `js/quote-data.js` 中 `newQuote()` |
| 配色方案 | `js/quote-color.js` 中 `schemes` |
| 明细表列 | `js/quote-categories.js` 的 `heads` 与 `addRow()`、`js/quote-preview.js` 的表头 |
| 税率默认值 | `index.html` 中 `#pqTaxRate` 的 value 与 `quote-data.js` 的 `tax_rate` |
| 版式与样式 | `css/style.css`、`js/quote-preview.js` 的 `buildFormalHtml()` |
| 单据编号规则 | `js/quote-storage.js` 的 `generateOrderNo()` |

## 六、目录结构

```
project-quote/
├── index.html          # 页面结构（编辑页/历史页/弹窗）
├── css/style.css       # 全部样式（含打印 @page A4 横向）
├── js/
│   ├── app.js                # 主应用：路由、保存、提示
│   ├── quote-storage.js      # 本地存储、编号生成、备份恢复
│   ├── quote-color.js        # 21 种配色方案
│   ├── quote-calculation.js  # 金额/税额计算（整数分防浮点误差）
│   ├── quote-categories.js   # 类目与明细行管理、图片上传
│   ├── quote-data.js         # 数据收集/校验/加载（统一数据模型）
│   ├── quote-preview.js      # 正式版面生成与预览（打印/导出共用）
│   ├── quote-export.js       # PDF/PNG 真实导出与打印
│   └── quote-history.js      # 历史单据列表
└── README.md
```

## 七、已知限制

- PDF/PNG 导出依赖 CDN 库，离线时自动回退为浏览器打印（可选"另存为 PDF"）。
- 数据存于浏览器本地，换电脑/换浏览器需先导出备份再导入。
